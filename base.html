用法
结构

手风琴 Accordion

那些库各自忠于一种平台语言。Prify 在令牌层做了统一抽象：同一套语义色、圆角、动效曲线，既能渲染成 M3 的表达，也能渲染成 Fluent 的表达。

prify.js 按 id/class 全局接管：缺 id 时静默降级（游离 div 兜底），因此同一套脚本可以服务多个模板页。
